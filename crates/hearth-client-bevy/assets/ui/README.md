# Original UI artwork

These assets were generated for hearth-rs with OpenAI's built-in image-generation
tool on 2026-08-29. They are original project artwork, not extracted from or
distributed with Hearthstone. Bevy embeds both PNGs into the executable through
`GameArtPlugin`, so the client does not depend on its working directory at runtime.

