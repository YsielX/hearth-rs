## LLM 陪玩与 Rust 教师接口

本版本新增 LLM 驱动的对手，可在图形客户端或 CLI 中使用，并提供可供后续训练直接复用的 Rust 请求与专家标签接口。

### 新功能

- **图形客户端 LLM 陪玩**：在「设置 → LLM 设置」填写 URL、模型名和 API Key，然后在选牌页选择「对战 LLM」。支持兼容 Chat Completions 的远程接口与本地模型。
- **后台思考与错误恢复**：LLM 请求在后台运行；对局菜单保持可操作。请求失败后可重试，或让已有启发式 bot 代走一步。
- **CLI LLM 玩家**：`--player-one llm` / `--player-two llm` 支持人机对弈、LLM 与启发式 bot 对弈，以及双方 LLM。
- **配置文件导入**：`--llm-env key.env` 支持 `OPENAI_API_URL` / `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL` 和对应的 `HEARTH_LLM_*` 变量；文件按字面解析，不执行 shell 命令。
- **模块化 `hearth-llm`**：请求构造、HTTP 调用、答案校验分离。输入包含当前玩家可见局面、己方已知牌组、选项语义、相关卡牌定义及可见历史；输出包含动作标签、理由、耗时及服务返回的 token 用量。
- **合法动作与过期回复校验**：按引擎合法动作列表选择动作，并在执行前核对局面指纹，防止旧请求的回复影响新局面。
- **凭据处理**：图形客户端输入的 Key 仅在进程内保留，不写入客户端设置、对局存档或回放；`key.env` 已加入 Git 忽略规则。

### 自 v0.1.0 以来的其他改进

- 将启发式 bot 的战术评估模块化，并统一 Rust 调用入口。
- 调整训练输入，向玩家观察暴露明确声明为公开的脚本计数器；移除学生学习路径中的战术规则，补充按需 LLM 教学与自博弈设计。
- 稳定脚本卡牌动作的索引顺序。
- 修复无尽瘟疫在替换抽牌后的重新洗牌行为。

### 快速开始

下载并解压对应平台的安装包，保留同目录的 `data/` 与 `decks/`。

Linux 图形客户端：

```bash
./hearth-client-bevy --llm --llm-env key.env --llm-model YOUR_MODEL
```

Windows PowerShell：

```powershell
.\hearth-client-bevy.exe --llm --llm-env key.env --llm-model YOUR_MODEL
```

`key.env` 示例（请替换为自己的配置）：

```dotenv
OPENAI_API_URL=https://your-provider.example/v1
OPENAI_API_KEY=YOUR_API_KEY
```

无需配置文件时，也可直接在图形客户端设置页面填写。CLI 使用同样的连接参数，例如：

```bash
./hearth-cli play --player-one llm --player-two bot --llm-env key.env --llm-model YOUR_MODEL
```

默认单次请求超时为 120 秒，可通过 `--llm-timeout` 调整。服务不支持 JSON 模式参数时，可在设置中关闭，或传入 `--llm-no-json`。完整说明见安装包内 `crates/hearth-llm/README.md`。

### 验证与范围

- 相关 Rust 单元及集成测试通过，覆盖请求投影、合法动作映射、过期回复、模拟 HTTP、配置导入和客户端行为。
- 已实际验证图形界面的输入、保存和 Key 遮罩。
- 使用 `gpt-5.6-sol` 完成两次真实局面请求：换牌约 15.3 秒，正常回合约 3.9 秒；返回动作均通过校验并由 Rust 引擎成功执行。该检查验证连接及执行链路，不代表完整对局稳定性或策略水平评测。
- LLM 当前按每个动作请求一次；训练查询门控、预算管理、并行对局调度和学生训练闭环仍由后续训练层实现。

提供 Linux x86_64 与 Windows x86_64 安装包及 SHA-256 校验文件。安装包不含任何账号凭据。
